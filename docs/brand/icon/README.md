# BookOn icon

The flag-on-the-green icon, as used for the site's app icon. Drawn for BookOn, so it's free to use anywhere.

## Which file to use

| Version                                        | Use it for                                                                                                     | Files                                  |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **bookon-icon** (rounded green tile)           | The everyday icon: app stores, email signatures, Stripe and Postmark branding, slides                          | svg, png 16 to 1024, pdf, jpg on white |
| **bookon-icon-square** (green, square corners) | Profile pictures on Instagram, Facebook, TikTok, LinkedIn, Mailchimp, Google: they round or crop it themselves | svg, png 400/512/1024, jpg, pdf        |
| **bookon-icon-circle**                         | Places that want a round picture already cut                                                                   | svg, png, pdf                          |
| **bookon-symbol-on-light**                     | The flag on its own, on white or light backgrounds                                                             | svg, png (see-through), pdf            |
| **bookon-symbol-on-dark**                      | The flag on its own, on green or dark backgrounds                                                              | svg, png (see-through), pdf            |
| **bookon-symbol-mono-black / -white**          | One colour: stamps, embroidery, engraving, single-colour print                                                 | svg, png (see-through), pdf            |
| **favicon.ico**                                | A browser tab icon (16, 32, 48 and 64 pixels in one file)                                                      | ico                                    |

- **SVG and PDF** are vector: they stay sharp at any size. Send these to designers and printers.
- **PNG** files have see-through backgrounds, except the green tiles themselves.
- The PDFs are 100 mm square.
