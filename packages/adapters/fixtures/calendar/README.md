# Calendar files for tests

Written by hand in the shapes Google Calendar ("secret address in iCal format") and Outlook
(published calendar) produce, with the cases BookOn has to get right: time zones (named,
defined, UTC and none), a weekly repeat with a skipped week and a moved week, all-day events,
events shown as free, cancelled events and BookOn's own lessons. None of it is anyone's
real calendar.
